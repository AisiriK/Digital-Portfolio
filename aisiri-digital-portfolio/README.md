# Aisiri Kiran's Digital Portfolio

A responsive one-page portfolio built with plain HTML, CSS and JavaScript. No build tools or package installation are needed.

## Preview locally

Open index.html in a web browser.

## Publish with GitHub Pages

1. Create a new GitHub repository for the portfolio.
2. Upload index.html to the root of the repository.
3. Open Settings → Pages in GitHub.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and the root folder, then save.
6. After GitHub Pages publishes the site, use the URL shown in the Pages settings.

The page includes Aisiri's email and LinkedIn profile. Review those contact details before making the repository public.
